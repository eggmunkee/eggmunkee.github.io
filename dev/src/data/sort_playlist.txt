# PlayList Sorting Instructions
#############################
# Objective: Sort all playlist JSON files (e.g., musicPlaylist_*.json) within the current working directory chronologically, from OLDEST to NEWEST.

# Source of Truth for Time: The absolute source for sorting is the **File System's Last Modified Date (mtime)** of the associated MP3 file or album art file.

# CRITICAL RULES:
# 1. DO NOT use dates found within the song titles, filenames, or metadata to determine order. These dates are considered part of the content and should be ignored for sorting purposes.
# 2. The file system's mtime is assumed to represent the intended "download order" (or placement order), not the actual creation date of the music. Use this order as the primary sort key.

# PATH AND ASSET DEFINITIONS:
# - Source MP3 Directory: /mp3/stochastic recovery 20x6
# - Playlist JSON File Location Pattern: dev/src/data/musicPlaylist_*.json

# FILE DISCOVERY AND ENRICHMENT:
# 1. Before sorting, perform a full directory listing of all audio assets (.mp3 files) within the Source MP3 Directory.
# 2. Compare the list of physical files against the assets listed in the JSON file's entries.
# 3. For any MP3 file found on disk that is NOT currently represented in a JSON entry, it MUST be added to the playlist array at the appropriate sorted position.

# Formatting for new entries:
# - "title": The title should be generated by taking the filename and stripping the extension (.mp3).
# - "artist": Use the default value "eggmunkee".
# - "album": Use the default value "STOCHASTIC RECOVERY 20x6".
# - "src": Use the full relative path to the source file (e.g., /mp3/stochastic recovery 20x6/[filename].mp3).
# Sorting Process:
# 1. Identify all JSON files listing audio assets.
# 2. For all listed and newly discovered MP3 assets, retrieve their mtime from the file system.
# 3. Sort the entire playlist array based on these retrieved mtimes (Ascending: Oldest to Newest).
